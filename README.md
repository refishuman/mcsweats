# mcsweats

Trade your used sports gear, and help music students in Brazil.

McSweats is a student-built marketplace for exchanging athletic equipment and
apparel. 50% of all proceeds are donated to Dona Gal Escola de Música, in
Teresina, Brazil, to support musical programs and instruments in this
under-resourced community.
